<Warning>
  This playground establishes a **real WebRTC session** using your device credential. Your
  microphone audio is streamed to the Humain servers. Use a sandbox credential to avoid
  production billing. Browser microphone permission is required.

  To try **Public Gateway** mode instead of a direct credential, switch the toggle below and
  paste a `pub_…` public ID. The gateway endpoint's origin allowlist must include this docs
  site's host or the request is rejected before it reaches your kiosk. WebRTC signalling
  (`webrtc/offer`, `webrtc/ice`, `/end`) and the voice media itself both go directly between
  your browser and the agent in this mode too — the gateway is only involved in opening the
  session and minting the session token — see [Public Gateway](/concepts/public-gateway).
</Warning>
